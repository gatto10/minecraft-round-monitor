⛏️ Minecraft Monitor

Ein-Klick-Installer für das Waveshare ESP32-S3-Touch-AMOLED-1.75.

Display per USB anschließen und diese Seite in Chrome oder Edge öffnen.

Nach dem ersten Start erzeugt das Display das WLAN „MinecraftMonitor-Setup“.

Danach mit dem WLAN verbinden und 192.168.4.1 im Browser öffnen. Die Monitor-API ist bereits mit 192.168.178.115:8080/api/status vorbelegt.
